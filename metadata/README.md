# Slang Metadata

## Overview

This folder stores contextual metadata associated with each slang word tracked in the project.

Metadata provides qualitative context that complements quantitative Google Trends data, enabling event-based analysis and spike correlation.

---

## 📌 Purpose

While Google Trends shows *when* interest changes, metadata helps explain *why* those changes occur.

By combining trend data with contextual events, the project enables deeper cultural and diffusion analysis.

---

## 📊 Metadata Fields

Each slang term will include the following attributes:

- **Word** – The slang term being analyzed  
- **Origin Year** – Approximate year the slang gained recognition  
- **Origin Country** – Country where the slang originated  
- **Origin Platform** – Platform where it first gained traction (e.g., Reddit, Twitter, TikTok)  
- **Major Spike Event** – Significant cultural or media event associated with a surge in interest  
- **Category** – Type of slang (e.g., meme culture, social commentary, internet humor, gaming, hip-hop)  
- **Notes** – Additional contextual observations  

---

## 🔍 Analytical Use Cases

- Event-based spike annotation  
- Correlation between media events and search surges  
- Diffusion pattern interpretation  
- Cultural lifecycle modeling  
- Cross-country adoption comparison
