# Dashboards

## Overview

This folder documents dashboards built using Looker Studio to visualize and analyze slang trend data.

The dashboards are powered by analytics-ready tables from BigQuery and are designed to highlight temporal patterns, peaks, and diffusion behavior.

---

## 📊 Phase 1 Dashboard

The initial dashboard focuses on a single slang term ("Karen") in the United States using Web Search data.

### Key Visualizations

- **Interest Over Time (Weekly)**  
  Line chart showing raw search interest over time.

- **4-Week Moving Average Overlay**  
  Smoothed trend line to reduce noise and highlight sustained momentum.

- **Peak Week Visualization**  
  Highlighting maximum interest points and spike periods.

- **Year Filter Control**  
  Interactive filtering for focused temporal analysis.
